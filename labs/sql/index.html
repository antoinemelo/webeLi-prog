Caractéristiques de l’atelier SQL

          
        

        

			
    
			  
  • Édition et exécution directe de requêtes SQL dans le navigateur (SQLite via WebAssembly).
    • 
			  
  • Coloration syntaxique :
				
      
				  
    • SELECT, FROM, WHERE, JOIN (mots-clés en évidence)
      • 
				  
    • NomTable (tables en couleur spécifique)
      • 
				  
    • 'Texte', 123 (chaînes et nombres)
      • 
				  
    • -- commentaire en gris
      • 
				
    
			  
    • 
			  
  • Chargement et enregistrement :
				
      
				  
    • Ouvrir / sauvegarder un fichier .sql
      • 
				  
    • Ouvrir / exporter une base .sqlite
      • 
				
    
			  
    • 
			  
  • Trois scripts au maximum : le nom actif est vert. La base et les résultats restent communs à tous les scripts. Réinitialiser concerne uniquement le script actif.
    • 
              
  • Projet : télécharger tous les scripts ouverts et la base SQLite dans un ZIP.
    • 
              
  • Sauvegarde locale : scripts et base de données stockés dans le navigateur.
    • 
			  
  • Affichage des résultats :
				
      
				  
    • Résultats des requêtes sous forme de tableau
      • 
				  
    • Exploration des tables, clés étrangères et métadonnées
      • 
				  
    • Diagramme entité-relation généré automatiquement
      • 
				
    
			  
    • 
			  
  • Partage rapide : génération d’un lien (URL encodée en Base64).
    • 
			  
  • Raccourcis pratiques :
				
      
				  
    • F9 = exécuter la requête
