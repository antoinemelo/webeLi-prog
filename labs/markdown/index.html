Caractéristiques de l’atelier Markdown

          
        

        

			
    
			  
  • Édition et rendu instantané de documents Markdown.
    • 
			  
  • Coloration syntaxique :
				
      
				  
    • # Titre, ## Sous-titre (titres en évidence)
      • 
				  
    • gras, italique, code (mises en forme repérées)
      • 
				  
    • Liens [texte](url), listes, images et citations formatées
      • 
				  
    • Blocs de code avec highlight.js
      • 
				
    
			  
    • 
			  
  • Snippets avec autocomplétion : titres, tableaux, citations, blocs de code, etc.
    • 
			  
  • Aperçu en direct via marked.js + coloration syntaxique (highlight.js).
    • 
			  
  • Sauvegarde locale : texte, position du curseur et défilement mémorisés.
    • 
			  
  • Documents longs : défilement interne visible; clic sur un numéro pour atteindre la ligne, double-clic pour la sélectionner.
    • 
			  
  • Export et impression :
				
      
				  
    • Téléchargement en .md ou export en .html
      • 
				  
    • Impression directe ou export PDF via l’imprimante
      • 
				
    
			  
    • 
			  
  • Nom de fichier auto-généré : Prénom_Objet-ObjetTPxx_YYYYMMDD.md.
    • 
			  
  • Partage rapide : génération d’un lien (URL encodée en Base64).
    • 
			  
  • Interface mobile-friendly avec redimensionnement dynamique et mode plein écran (F11).
    •
