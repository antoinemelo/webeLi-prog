    • Gestion des fichiers virtuels
				
        
					
      • L’appel à open("f.txt", "r/w") crée un onglet (3 max.); expl. avec
					
        
with open("fichier.txt","w") as f:
    f.write("Hello world")
with open("fichier.txt") as f:
    print(f.read())
					
        
					
        • 
					
      • Le contenu du fichier est éditable directement dans cet onglet
        • 
					
      • Les modifications faites par le code Python et celles faites à la main restent synchronisées
        • 
				
      
			
      • 
			
    • Turtle
			  
        
				
      • import turtle ouvre automatiquement un canevas dans la zone Résultat; expl. avec
				
        import turtle
t = turtle.Turtle()
for _ in range(4):
    t.forward(100)
    t.left(90)
turtle.done()
        
				
        • 
				
      • Chaque exécution efface et recrée un nouveau canevas
