      Caractéristiques de l’atelier HTML / CSS
      
          
        
      
        
      
			
        
			  
      • Édition et prévisualisation de pages HTML et CSS directement dans le navigateur
        • 
			  
      • Coloration syntaxique
				
          
				  
        • <h1>, <p>, <div> (balises HTML, mises en valeur)
          • 
				  
        • class, id (attributs colorés)
          • 
				  
        • "texte", 123 (chaînes et nombres)
          • 
				  
        • <!-- commentaires --> et /* commentaires CSS */ en gris
          • 
				
        
			  
        • 
			  
      • Indentation intelligente
				
          
				  
        • Entrée = saut de ligne avec indentation automatique après une balise ou une accolade CSS
          • 
				  
        • Fermeture automatique des balises : <div> → insertion de </div>
          • 
				  
        • Suppression intelligente des paires (balises, guillemets, parenthèses) avec Backspace
          • 
				
        
			  
        • 
			  
      • Gestion des paires : parenthèses, guillemets et chevrons < > fermés automatiquement
        • 
			  
      • Trois documents au maximum : cliquez sur leur nom en haut pour changer de document. Le document actif est vert ; le bouton + crée un document et disparaît à trois. Fichier, Partager et Réinitialiser concernent le document actif. Projet télécharge tous les documents ouverts et les CSS communs.
        • 
			  
      • Sauvegarde locale : code, position du curseur et défilement mémorisés.
        • 
			  
      • Chargement et enregistrement
				
          
				  
        • Ouvrir un fichier HTML ou un projet ZIP contenant le HTML et ses CSS
          • 
				  
        • Enregistrer ou télécharger avec nom auto-généré (Prénom_Thème-ObjetTPxx_YYYYMMDD.html)
          • 
				
        
			  
        • 
				
      • Gestion des fichiers CSS virtuels
					
          
						
        • Créer ou importer les CSS avec le menu Projet. La balise <link> correspondante est ajoutée si nécessaire.
          • 
						
        • Les documents HTML partagent les CSS affichés à droite ; changer de document conserve les onglets ouverts. Le bouton + apparaît après la création ou l’import d’un fichier.
          • 
						
        • La croix × ferme l’onglet sans supprimer le CSS : il reste appliqué et inclus dans le ZIP. Projet → Fichiers fermés permet de le rouvrir.
          • 
					
        
				
        • 
			  
      • Partage rapide : génération d’un lien (URL encodée en Base64)
        • 
			  
      • Aperçu en direct
				
          
				  
        • Rendu de la page dans une iframe sécurisée (sandbox)
          • 
				  
        • Images locales chargées en une fois depuis le dossier du projet et adaptées à la largeur de l’aperçu
          • 
				  
        • Les CSS liés à la page sont appliqués lors du clic sur Aperçu, même si leurs onglets sont fermés.
          • 
				
        
			  
        • 
			  
      • Raccourcis pratiques : F9 = afficher l’aperçu
        •
