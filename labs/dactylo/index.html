Atelier dactylographie
  • Deux modes d'entraînement
    • Technique — apprentissage précis des touches, clavier affiché, validation stricte des frappes
    • Vitesse — toutes les frappes comptent, calcul automatique du rythme (CPM) et des erreurs/minute
  • Deux modes d’affichage du texte de référence
    • Bloc — texte continu avec suivi dynamique du caractère et du mot en cours
    • Cartes — texte affiché caractère par caractère, y compris l’indication des retours à la ligne
  • Surlignage intelligent
    • Le caractère en cours apparaît en vert
    • Le mot en cours est mis en évidence
    • Les caractères spéciaux sont affichés en orange
    • Les erreurs apparaissent en rouge dans le texte de référence
  • Clavier visuel QWERTZ - Suisse romande
    • Affiché automatiquement en mode Technique
    • La touche à presser est surlignée en temps réel
    • Gestion complète des accents, majuscules, symboles et touches spéciales
  • Chargement d’un texte personnalisé
    • Import ou glisser-déposer d’un fichier .txt
    • Compatible avec tous les modes d’affichage (bloc ou carte)
  • Statistiques en direct
    • Nombre total d’erreurs
    • Durée écoulée
    • Frappe/minute (CPM) en mode Vitesse
    • Erreurs/minute (EPM) en mode Vitesse
  • Système complet de sauvegarde
    • Enregistrer — sauvegarde dans le fichier SQLite ouvert
    • Enregistrer sous… — création d’un nouveau fichier SQLite
    • Télécharger — export direct d’une copie de la base
    • Ouvrir — restauration d’une progression depuis un fichier SQLite
    • La progression est automatiquement répercutée dans l'application
  • Persistance automatique
    • La session de travail (base SQLite) se recharge automatiquement au démarrage
    • Les scores restent synchronisés avec le navigateur web
  • Données privées
    • Toutes les données sont stockées localement dans votre navigateur web ou dans vos fichiers
    • AUCUNE information personnelle n’est transmise en ligne
